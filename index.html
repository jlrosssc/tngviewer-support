TNG Viewer Support

Help and support for the TNG Viewer iOS app

Who this app is for

TNG Viewer is intended for people who already have an approved login on a genealogy site built with TNG. It works with any TNG site, as long as the free tng_api.php script has been installed on it (instructions below). Signing in with your approved account unlocks the app's additional visual and mapping capabilities — family photos and documents, and interactive maps of the places in the family tree. If you don't have a login yet, ask the administrator of your family's TNG site for one.

Getting connected

What do I need to use TNG Viewer?

TNG Viewer connects to a family tree website built with The Next Generation of Genealogy Sitebuilding (TNG). You'll need three things:

  • An approved TNG login — the same username and password you use on the TNG website. Logins are issued by the site's administrator.
  • The web address of the TNG site (for example, https://example.com/genealogy).
  • The tng_api.php script installed on that site — see the instructions below. If you're not the site's administrator, ask them to install it.

Quick start

  1. Download tng_api.php from our GitHub page and upload it to the TNG site's root folder — the same folder that contains TNG's config.php.
  2. Verify the install by visiting https://yoursite.com/your-tng-path/tng_api.php?action=ping in a browser and checking for "success": true.
  3. In the app, enter the site's base URL on the setup screen and tap Connect.
  4. Sign in with your approved TNG username and password to unlock photos, documents, and maps.

How do I install the API script on my TNG site?

TNG Viewer talks to your site through a small script called tng_api.php. Download it from our GitHub page (use the download button there), then upload it to your TNG root directory — the same folder that contains TNG's config.php — using FTP, SFTP, or your web host's file manager. No TNG configuration changes are needed. If you get stuck, email us and we'll walk you through it.

How do I check that the script is installed correctly?

In any web browser, visit https://yoursite.com/your-tng-path/tng_api.php?action=ping. If you see a short response that includes "success": true, the script is installed and reachable. If you see a "not found" page instead, the script isn't in the right folder — it must sit next to config.php.

What do I enter on the app's setup screen?

Enter the base URL of the TNG installation — the address of the page where TNG is hosted, without any .php filename. For example, if you view a tree at https://example.com/genealogy/index.php, enter https://example.com/genealogy. You can leave off https://; the app adds it automatically. Then tap Connect.

The app says "Cannot find host" or "Connection timed out."

Check the address for typos, and confirm the site opens in Safari on the same device. If the site works in Safari but not in the app, make sure you entered the base URL (no .php at the end) and that tng_api.php responds to the ping test above.

The app reports an SSL or HTTPS error.

iOS expects sites to use HTTPS. If your TNG site doesn't have an SSL certificate, the connection may fail or you may need to enter the address with http:// explicitly. The best fix is to add an SSL certificate to your site — most web hosts offer free certificates via Let's Encrypt. Email us if you're stuck and we'll help.

Do I have to sign in?

Yes — the app is intended for people who already have an approved TNG login. Sign in with the same username and password you use on the website. Signing in unlocks protected records, data for living persons, and the app's additional visual and mapping capabilities, subject to the access rights your site administrator has given your account. Your credentials are stored securely in the iOS Keychain on your device. If you don't have a login, ask the administrator of the TNG site for one.

How do I switch to a different TNG site?

Open the Settings tab in the app and choose Change Site URL, then enter the new site's address. To start completely fresh, Settings also offers Reset App, which clears the saved site and sign-in.

Frequently asked questions

I can't see photos or certain people in the tree.

TNG sites control visibility per user. If records or media appear on the website but not in the app, contact your site administrator to confirm your account's access rights, or email us and we'll help figure out what's going on.

How do I request a new feature?

Email us or open a GitHub issue describing what you'd like the app to do. We review every request.

What TNG Viewer does

TNG Viewer is a companion app for browsing a family tree hosted with The Next Generation of Genealogy Sitebuilding (TNG), letting you search people, view family details, and browse photos from your phone or tablet.
